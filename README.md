# Portal Mapping GKI di Sekitar Kajadu

Peta dan direktori Jemaat, Bakal Jemaat, dan Pos Jemaat GKI Sinode Wilayah Jawa Tengah dan Jawa Barat di sekitar Klasis Jakarta II (Jakarta Selatan, Tangerang, Depok, Bogor), lengkap dengan alamat, jadwal ibadah Minggu, dan rute.

Buka portal: https://nosusiwi.github.io/

Seluruh portal ada di satu file, `index.html`. Untuk memperbarui data, ganti file itu lalu commit; GitHub Pages menerbitkan ulang otomatis dalam 1–2 menit.

Sumber data: situs GKI SW Jawa Tengah (gkiswjateng.org), GKI SW Jawa Barat (gkiswjabar.org), situs/media sosial tiap jemaat, dan OpenStreetMap. Diambil 26 Oktober 2026.
